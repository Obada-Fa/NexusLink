# NexusLink Agent Guidelines
- **Always Communicate Continuously:** The user is on a mobile client. Always stream visible explanatory text before and during tool executions.
- **Never Fail in Silence:** If a tool call or command encounters an error or requires user confirmation, immediately inform the user with actionable next steps.
- **Current UX plan:** Nexus app refinements follow [`docs/NEXUS-REFINE-PLAN.md`](docs/NEXUS-REFINE-PLAN.md). Check it (and its progress log) before changing Home, pairing, navigation or module screens.

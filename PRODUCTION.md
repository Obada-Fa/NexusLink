# Production Checklist

## Tauri Packaging (Desktop Host)

- [ ] Set `tauri.conf.json` bundle identifiers, app name, version
- [ ] Generate signing keys for macOS/Windows
- [ ] Configure update server URL in `tauri.conf.json > updater`
- [ ] Build: `cd apps/desktop && bun run tauri build`
- [ ] Test installer on each target OS
- [ ] Verify auto-updater endpoint returns valid JSON
- [ ] Bundle sidecar binary (`nexuslink-sidecar`) next to app binary

## HTTPS Requirement

- [ ] Desktop Bun RPC server (port 45678) must serve over TLS in production
- [ ] Desktop Next.js dev server must use HTTPS in production (behind reverse proxy or direct TLS)
- [ ] Mobile PWA requires HTTPS for Service Worker registration
- [ ] Use Let's Encrypt or internal CA; certificate rotation automated
- [ ] Configure CSP headers restricting WebSocket origins to known hosts

## Signaling Server Deployment (Relay)

- [ ] Deploy `apps/relay` to a persistent server (VPS, fly.io, railway)
- [ ] Set `RELAY_PORT` env var (default 3033)
- [ ] Configure TLS termination (nginx, Caddy, or Bun TLS directly)
- [ ] Health check endpoint: `GET /health` → `{ ok: true, rooms: N }`
- [ ] Set up process manager (systemd, pm2, docker) with auto-restart
- [ ] Monitor: room count, message throughput, connection churn
- [ ] Configure firewall to allow WebSocket port only
- [ ] Rate-limit new room creation if exposed publicly
- [ ] Set `RELAY_ROOM_EXPIRY_MS` shorter than default 30 min if needed

## Relay Hosting Options

- **Bun standalone**: `bun build src/index.ts --target=bun --outdir=dist && bun run dist/index.js`
- **Docker**: `FROM oven/bun`, copy source, `bun run src/index.ts`
- **fly.io**: `fly.toml` with `[http_service] internal_port = 3033`
- **railway**: deploy from repo, set start command to `cd apps/relay && bun run src/index.ts`

## Mobile Client Install

### PWA (Recommended)

- [ ] Serve `apps/mobile-client` build output over HTTPS
- [ ] Verify `manifest.json` includes `name`, `short_name`, `icons`, `start_url`, `display: standalone`
- [ ] Verify `service-worker.js` generated by next-pwa
- [ ] Test "Add to Home Screen" on iOS Safari and Android Chrome
- [ ] Verify offline fallback page works (service worker pre-caches shell)
- [ ] Set `theme-color` and `apple-mobile-web-app-capable` meta tags

### Native Wrapper (Optional)

- [ ] Wrap PWA in Capacitor or Tauri mobile
- [ ] Configure native WebSocket permissions (iOS ATS exceptions, Android cleartext)
- [ ] Test deep linking from `/pair` page to native pairing flow

## Security

- [ ] ECDH key exchange must use production key pair (not dev stubs)
- [ ] TOTP verification must reject codes outside 30-second window
- [ ] Session tokens must be random, ≥128-bit entropy, with server-side expiry
- [ ] All WebSocket connections must validate token on `session.heartbeat` / first message
- [ ] Rate-limit `session.pair` and `session.authenticate` calls per IP
- [ ] Audit RPC handlers: no `exec` without allowlist, no path traversal in `fs.*`
- [ ] Screen capture permission must be user-granted (OS-level prompt, not auto)
- [ ] Relay rooms must be scoped to authenticated users in production (currently open)

## Monitoring & Logging

- [ ] Structured JSON logging for relay and desktop server
- [ ] Alert on: relay unhealthy, desktop server crash, connection flood
- [ ] Track: active rooms, connected peers, message latency, error rates
- [ ] Set up health check monitoring (UptimeRobot, Grafana, Datadog)

## Pre-Launch Verification

- [ ] Run `bun test` — all tests pass workspace-wide
- [ ] Run `bun run build` — all apps build cleanly
- [ ] Manual pairing test: desktop ↔ mobile over relay
- [ ] Manual terminal test: shell spawn, input, resize, kill
- [ ] Manual files test: list, navigate, delete (with confirmation)
- [ ] Manual processes test: list, sort, filter
- [ ] Manual mirror test: screen start/stop, gesture overlay
- [ ] Test reconnect: kill relay, verify mobile shows reconnect button
- [ ] Test error boundaries: force throw in page, verify error.tsx renders
- [ ] Test loading states: slow network, verify loading.tsx renders
